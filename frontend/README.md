# CashGuard AI — Frontend

CashGuard AI is a modern financial management SaaS platform built to help businesses manage clients, invoices, payments, reminders, cash flow, and financial insights.

This repository contains the **React + TypeScript frontend** of CashGuard AI.

## 🚀 Features

- Responsive financial dashboard
- Client management
- Invoice builder
- Invoice preview
- PDF invoice generation
- Payment tracking
- Payment reminders
- AI financial insights
- Cash flow forecasting
- Business health dashboard
- AI Finance Copilot
- Negotiation Assistant
- Real-time notifications
- Light/Dark theme
- Responsive and modern SaaS UI

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- Socket.IO Client
